# EPDP — Estudo Profundo de Português

Plataforma educacional em desenvolvimento com React, TypeScript e Vite. A integração de autenticação, banco de dados e armazenamento será feita com Supabase.

## Executar

```bash
npm install
npm run dev
```

Configure as variáveis de ambiente usando `.env.example`. Nunca publique chaves privadas no repositório.

## Etapa atual
Estrutura inicial e interface responsiva de demonstração. Login, cadastro, persistência, avaliações completas e jogos serão implementados nas próximas etapas.
